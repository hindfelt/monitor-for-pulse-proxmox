## Description
Monitor for Pulse is a phone-first client for Pulse, the self-hosted monitoring tool for Proxmox. Open it and see straight away whether everything is OK and, if it isn't, what to do about it.

AT A GLANCE
• Node CPU, memory, disk and temperature gauges
• How many guests are running
• A short list of what needs attention, including guests with no backup, overdue backups and filling disks

GUESTS
• VMs and containers with clear CPU, memory and disk bars
• Search by name, ID or tag, and filter to what needs attention
• Sort by issues, CPU, memory, disk or name

WIDGETS
• Home Screen widgets in three sizes
• Lock Screen widgets for a quick status check
• Issues, CPU, memory, disk and temperature without opening the app

DETAILS
• History charts for the last hour, day or week
• A forecast of when a disk will fill up
• Plain-language steps for fixing each issue
• Storage and alerts in their own tabs

PRIVATE AND READ-ONLY
• Connects only to your own Pulse server, over HTTPS
• Your token stays in secure storage on your device
• No account, no analytics, no tracking
• It can't change anything on your servers

You need your own Pulse server, reachable over HTTPS with a valid certificate, and an API token with read-only monitoring access. You can try the app first with built-in demo data.

Monitor for Pulse is an independent project, not affiliated with the Pulse project.

## Notes for App Review (iPhone)
This app is a client for Pulse, self-hosted server monitoring software. It requires the user's own server, so no login is supplied. To review all features, tap "Try it with demo data" on the first screen. Demo mode uses built-in sample data and needs no network or account.

The app is read-only, has no accounts or purchases, and connects only to the HTTPS server address the user enters. The local network description is needed because many users run Pulse on their home network.

## Notes for App Review (Mac)
This app adds a desktop widget for Pulse, self-hosted server monitoring software. To review it, click "Try with Demo Data" in the window that opens at first launch, then right-click the desktop, choose Edit Widgets and add Monitor for Pulse. The app stays in the menu bar because it fetches data for the widget. "Open at login" is off by default and only the user can turn it on.
