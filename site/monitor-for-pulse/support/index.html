Monitor for Pulse

Your Proxmox homelab at a glance

A read-only app and Mac widget for Pulse, the self-hosted monitoring tool. You need your own Pulse server. Monitor for Pulse is an independent project, not affiliated with the Pulse project.

New here? Read the illustrated setup guide →

Get started

  1. Make sure Pulse is available over HTTPS with a valid certificate.
  2. In Pulse, go to Settings → API Access and create a token with only Monitoring & alerts (read).
  3. Enter the address and token in the app. To look around first, choose Try it with demo data.
  4. On a Mac, right-click the desktop, choose Edit Widgets… and add Monitor for Pulse.

Common questions

Why is HTTPS required?

Your API token is sent with every request, so the connection has to be encrypted. Put Pulse behind a reverse proxy with a certificate from a public authority. A self-signed certificate works only if your device trusts it.

The app can't reach Pulse

  • Open the same address in your device's browser. It should load without a certificate warning.
  • Away from home, turn on your VPN if Pulse is only on your own network.
  • Check Local Network under your device's privacy settings, and allow the app.

It says the token was rejected

Create a new token with the scope above, and check that you copied all of it.

Why is temperature missing?

Pulse only has temperatures once the Pulse agent is installed on the Proxmox host. Check that Pulse itself shows one.

Why isn't the Mac widget up to date?

The Mac app fetches for the widget, so it has to be running in the menu bar. You can turn on Open at login in its settings. macOS decides when widgets redraw, so there can be a delay.

Can the app change anything on my servers?

No. It only reads monitoring data.
